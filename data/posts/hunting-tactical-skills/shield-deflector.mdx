## 技能数值

| 属性 | 数值 |
| --- | --- |
| 单次临时护盾 | 目标 **15% 最大生命值** |
| 脉冲次数 | **5 次**，每隔 **6 秒**发出一次 |
| 脉冲时序 | 脉冲计时开始后的第 3、9、15、21、27 秒 |
| 脉冲范围 | 基础半径 8 米，扩张曲线末值约 **40 米** |
| 单次脉冲区域时长 | 0.55 秒，在区域结束时检测友方 |
| 护盾持续时间 | **10 秒** |
| 护盾叠加 | 最多 **5 层**，再次获得时刷新时长 |
| 配置冷却与储存上限 | 30 秒，1 次 |

装置激活时长为 **30 秒**。吃到脉冲的友方获得临时护盾，同时获得 **10 秒抗击飞**，再次获得时刷新计时。
