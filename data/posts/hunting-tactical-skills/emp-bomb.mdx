## 技能数值

| 属性 | 数值 |
| --- | --- |
| 基础伤害 | 每个命中敌人 **9,000** |
| 伤害类型 | 电弧技能伤害 |
| 引爆次数 | **1 次**，每个命中敌人各结算一次 |
| 爆炸半径 | **10 米** |
| 破韧 | 9 |
| 易伤 | 受到伤害提高 **<StarshipEmpVulnerability />**，配置持续 **5 秒** |
| 眩晕 | **3 秒**，适用于非首领敌人 |
| 暴击与弱点 | 均不触发 |
| 配置冷却与储存上限 | 30 秒，1 次 |

爆炸先结算电弧伤害，再对命中敌人施加易伤。首领也受易伤影响。
