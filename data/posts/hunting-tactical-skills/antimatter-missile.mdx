## 技能数值

| 属性 | 数值 |
| --- | --- |
| 基础伤害 | 每个命中敌人 **27,000** |
| 伤害类型 | 物理技能伤害 |
| 爆炸次数 | **1 次**，每个命中敌人各结算一次 |
| 爆炸半径 | **7.5 米** |
| 导弹下落时间 | 3 秒 |
| 破韧 | 27 |
| 暴击与弱点 | 均不触发 |
| 配置冷却与储存上限 | 30 秒，1 次 |

导弹落地后，对范围内未被遮挡的敌人进行一次爆炸判定。伤害结算的击飞仅在击杀时触发。
