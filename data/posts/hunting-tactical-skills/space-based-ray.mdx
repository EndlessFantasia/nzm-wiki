## 技能数值

| 属性 | 数值 |
| --- | --- |
| 锁定目标 | 1 个，最远 80 米 |
| 基础伤害 | 每跳 **1,500** |
| 伤害类型 | 物理技能伤害 |
| 破韧 | 每跳 1.5 |
| 结算间隔与窗口 | 每 0.25 秒，持续 6.1 秒 |
| 完整命中 | 估算 **24–25 跳**，基础伤害合计 **36,000–37,500** |
| 暴击与弱点 | 均不触发 |
| 配置冷却与储存上限 | 30 秒，1 次 |

射线进入激活状态后延迟 **0.2 秒**启动周期结算。6.1 秒内包含 24 个完整的 0.25 秒间隔。
